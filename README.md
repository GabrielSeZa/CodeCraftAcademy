
# CodeCraft Academy

CodeCraft Academy es un sitio web educativo desarrollado como proyecto académico, cuyo propósito es presentar una plataforma introductoria de cursos de programación y desarrollo web.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido del sitio web.
- **CSS3:** diseño visual, estilos y adaptación a diferentes pantallas.
- **JavaScript:** interactividad, filtrado de cursos y funcionamiento de la navegación y el formulario.

## Funcionalidades

- Página de inicio con presentación de la academia.
- Catálogo de cursos de HTML5, CSS3, JavaScript y Python.
- Filtro interactivo para seleccionar cursos por tecnología.
- Menú de navegación adaptable a dispositivos móviles.
- Formulario de contacto demostrativo con validación y mensaje de confirmación.
- Diseño responsivo para computadoras, tabletas y celulares.
- Características de accesibilidad, como navegación mediante teclado y etiquetas semánticas.

## Cómo ejecutar el proyecto

1. Descargar o clonar este repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en un navegador web.

No es necesario instalar dependencias ni configurar un servidor para visualizar el sitio.

## Validación y accesibilidad
